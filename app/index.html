Next steps

  • Open the wiki Read and edit your team's pages. Every answer the brain gives cites the page it came from. Open the wiki
  • Connect a model Bring your own model key in Settings. Until you do, the managed model answers. Open Settings
  • Connect your coding agent (MCP) Your agent reaches the brain at this endpoint:
    1. Create a personal access token in Settings → API tokens. It is shown once.
    2. Add the server to your agent with the token as a bearer header, for example: claude mcp add --transport http livingbrain --header "Authorization: Bearer <token>"
    3. In a terminal, livingbrain login signs the CLI in with the OAuth device flow instead — no token to copy. Point it here with LIVINGBRAIN_API_URL=.

Sign in

Four ways in, all equal. Slack is one option here, not a requirement: a workspace without Slack is a first-class workspace.

Email magic link

We mail a single-use link. We never say whether an address belongs to anyone — every address gets the same answer, so this form cannot be used to find out who is in a workspace.

Other ways in

  • Slack Connect a Slack team. Your workspace is ours, not Slack's, so you can leave Slack later without losing the brain. Continue with Slack
  • Passkey Deferred: passkeys move with the follow-up identity work (ADR 0002), so there is no server route to sign in with yet. Not available yet
  • Discord Discord is planned as an equal team chat alongside Slack (#56). There is no OAuth route yet, so this button does nothing. Not available yet
  • Ask, or connect an agent The CLI and coding harnesses sign in over MCP and the device flow, then share the same session. Not in this app yet
