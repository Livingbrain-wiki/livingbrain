      GitHub

      Living Brain reads the repositories you include, read only: commits, issues and pull requests. Each repository files under its own name as a project, so agent sessions from the same repository land beside them.

      GitHub asks which account and which repositories, read only. Then it asks you once to authorize Living Brain, which proves you are the person who installed it. Nothing is read until a repository is included.

      GitHub isn't configured on this deployment.

        Repositories

        Shared repositories serve the whole workspace; personal ones only you. Backfill runs on the server's schedule, and the progress shows here. To add or remove repositories, or to disconnect, use Manage on GitHub.
