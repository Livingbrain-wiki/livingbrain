The Living Brain workspace is one Rust Cargo workspace, consumed as a Cratefield
venture and deployed as a single Cloudflare Worker. Two kinds of crate, and the
split is a rule rather than a preference: the module crates depend on ports and
never on a runtime, and exactly one crate names the Worker SDK. That rule is
what keeps a native-only dependency from reaching a module in the first place.

Nothing in this file should ever be redacted. It is the negative corpus: ordinary
prose, ordinary code and ordinary build metadata, the sort of thing a workspace
ingests every day. If a detector fires on any of it, the detector is wrong.

Ordinary prose
--------------
The design draws on an earlier note-taking system, licensed under a permissive
licence, and on ideas for a memory model that treats recall as a first-class
concern. Neither project's source is vendored here; where a pattern or a line of
code is reused, the file that reuses it says so in a comment above the import.

Deployment happens on a merge to the main branch. The build matrix covers the
toolchain on Linux and on macOS, and the conformance suite runs against both a
file-backed database and a server one, so a module that only works against the
easy dialect is caught before review rather than after it.

Reading a log line usually takes less time than deciding whether to read it. The
ingest path therefore makes the cheap decision first: if the text looks safe it
is stored as it arrived, and if it does not, the caller is told what class of
thing was removed without being told what the thing was.

use std::sync::LazyLock;

static RULES: LazyLock<Vec<Compiled>> = LazyLock::new(|| compile_all());

/// A detector is a name and a pattern. The name is what a log line shows.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Shape {
    /// A token with a known vendor prefix.
    Prefixed,
    /// A shape we only recognise from context.
    Structural,
}

impl Shape {
    const fn label(self) -> &'static str {
        match self {
            Self::Prefixed => "prefixed",
            Self::Structural => "structural",
        }
    }
}

fn compile_all() -> Vec<Compiled> {
    let specs = load_specs();
    specs.iter().map(compile_one).collect()
}

#[test]
fn overlapping_detectors_resolve_deterministically() {
    let specs = load_specs();
    let first = compile_one(&specs[0]);
    let second = compile_one(&specs[1]);
    assert_eq!(first.shape(), second.shape());
    assert!(first.pattern().len() > 0);
}

from dataclasses import dataclass
from datetime import datetime, timezone


@dataclass(frozen=True)
class Event:
    kind: str
    at: datetime
    payload: dict

    def age_seconds(self) -> float:
        now = datetime.now(timezone.utc)
        return (now - self.at).total_seconds()


def summarise(events: list[Event]) -> str:
    if not events:
        return "no events"
    counts = {}
    for event in events:
        counts[event.kind] = counts.get(event.kind, 0) + 1
    return ", ".join(f"{k}={v}" for k, v in sorted(counts.items()))
